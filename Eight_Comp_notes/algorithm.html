Looping

Activity – 3

Write pseudocode of rolling a dice program between players, turn by turn. If dice rolls a 6, the same player rolls the dice again.

Line 0:START
Line 1:SET player = 1
Line 2:SET totalPlayers = 2
Line 3:WHILE game is not finished DO
Line 4:    DISPLAY "Player", player, "turn"
Line 5:    REPEAT
Line 6:        dice ← RANDOM number between 1 and 6
Line 7:        DISPLAY "Player", player, "rolled:", dice
Line 8:    UNTIL dice ≠ 6
Line 9:    player = player + 1
Line 10:    IF player > totalPlayers THEN
Line 11:        player = 1
Line 12:    END IF
Line 13:END WHILE
Line 14:END

Conditional Statement

Write pseudocode, that compare three different numbers A, B and C and find out the largest number.

Line 0:START
Line 1:DISPLAY "Enter three numbers A, B, and C"
Line 2:INPUT A, B, C
Line 3:IF A > B AND A > C THEN
Line 4:    DISPLAY "A is the largest number"
Line 5:ELSE IF B > A AND B > C THEN
Line 6:    DISPLAY "B is the largest number"
Line 7:ELSE
Line 8:    DISPLAY "C is the largest number"
Line 9:END IF
Line 10:END
