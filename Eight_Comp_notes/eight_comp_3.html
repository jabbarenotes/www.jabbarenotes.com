Problem: A problem is a challenge or situation for which a solution is required.

Problem Solving: Solving these challenges is called Problem Solving.

Types of Problems: Not all problems are the same. We can put them into three main groups:

  • 1. Simple Problems: These are small and easy. You just follow a few clear rules. There is usually only one right answer. Example: Sharpening a pencil or finding a page in a book.
  • 2. Complicated Problems: These are a bit harder. You need special skills or more knowledge (expertise) to solve them. Example: Fixing a broken toy or solving a hard math puzzle.
  • 3. Complex Problems: These are very difficult. You need to work with other people (collaboration) and spend a lot of time and effort to find a solution. Example: Planning a big school event or cleaning up a whole neighborhood.

Computers are great tools. They help us solve problems in almost every subject we study. We use computers due to the following reasons:

  • Speed: Technology is moving very fast. Computers can do billions of tasks (operations) in just one second!
  • Accuracy: They help us solve problems correctly without making small mistakes.
  • Efficiency: They save us a lot of time and hard work.

The Information Processing Model describes how a computer converts data into useful information through different stages.

Features of Information Processing Model:

  1. Input: Data is entered into the computer using input devices such as a keyboard or mouse.
  2. Processing: The CPU processes the data according to given instructions (programs) to produce meaningful results.
  3. Output: The processed information is displayed to the user through output devices like a monitor or printer.
  4. Storage: Data and results are stored in memory for future use.
  5. Feedback: The output can be used again as input to improve or continue the process.

Sometimes a problem is very large and cannot be solved in one step. In the Information Processing Model, we solve it by repeating the same steps again and again.

Explanation:

  • Iteration (Repeat): The steps Input → Processing → Output are repeated many times.
  • Intermediate Results: Each time we repeat the steps, we get a small result (partial answer).
  • Final Goal: These small results combine together to solve the complete problem.

Steps to solve a problem are as follows:

  1. Understand the Problem
  2. Formulate a Model
  3. Develop an Algorithm
  4. Write the Program
  5. Test the Program
  6. Evaluate the Solution

Before you try to solve a problem, you must know what you can do and what you cannot do. This is called defining the Scope and Limitations.

Scope: The Scope is like a boundary line. It tells you exactly what your solution must do to finish the job. It is the part of the problem you can control and fix.

Limitation: A Limitation is something that is outside of your control. It is a part of the problem that you cannot fix or change at this time.

Example 1: Making a Simple Calculator

  • Scope: Your calculator is made to do four things: Add, Subtract, Multiply, and Divide. These are the only jobs it must do.
  • Limitation: Your calculator cannot do "Square Roots" or "Percentages." Those extra tasks are limitations because they are not part of your plan.

Example 2: Email Not Working

  • Scenario A (Limitation): You ask your brother, and his email is also not working. This means the Internet Provider has a problem. You cannot fix the whole internet yourself, so this is a Limitation.
  • Scenario B (Scope): Your brother’s email is working perfectly. This means the problem is only on your computer. Since you can check your own settings, this is within your Scope.

Humans and computers both solve problems, but they do it in very different ways.

Human as a Problem-Solving Tool:

  • Humans use thinking, understanding, and experience.
  • They can make decisions even if the information is incomplete.
  • Humans can be creative and flexible.
  • Sometimes, humans can make mistakes.

Computer as a Problem-Solving Tool:

  • A computer follows instructions given by a human (program).
  • It works very fast and accurately.
  • It cannot think or make decisions on its own.
  • It needs step-by-step instructions.

Fundamental Difference:

👉 The main difference is: Humans think and decide on their own, while computers only follow instructions.

There are some problems that a computer can never solve correctly, no matter how much time it has. The most famous one is the Halting Problem.

  • The Question: Can we write a program that looks at any other program and tells us if it will eventually stop (halt) or if it will run forever?
  • The Answer: No. It is mathematically impossible to make a program that gets this right every single time.

Before we start building a program on a computer, we must first design a plan. We use algorithms for this. An algorithm is a clear, step-by-step way to solve a problem.

There are two main ways to show these steps:

  • 1. Flowchart: A drawing or picture of the steps.
  • 2. Pseudocode: A way to write the steps using simple, plain English.

Computers are powerful, but they have limited resources. This means they only have a certain amount of "brain power" (CPU) and "memory" (RAM) to use. Because of this, we must use these resources wisely.

Every computer program is built using an Algorithm. An algorithm is just a list of steps to solve a task.

Algorithmic Efficiency is the measure of how well an algorithm uses a computer’s resources, like CPU time and memory, while solving a problem.

Example:

  • Two algorithms can solve the same problem.
  • The one that finishes faster and uses less memory is more efficient.

Pseudocode is a simple way to write down an algorithm. It uses "notes" and "easy text" instead of hard computer code.

Why is it helpful?

  • It is written in plain English, so it is easy to read.
  • It helps a programmer change the plan into any computer language they like.

To Write pseudocode follow these steps:

Step 1: Plan the Logic
Before you write anything, think about the problem in your head.

Step 2: Write the Main Goal
At the very top of your paper or screen, write a clear sentence that says what the pseudocode is for.

Step 3: Write the Steps (The Algorithm)
Now, write down the actual instructions. Use these three common patterns: Sequences, Repetitions (Loops) and Conditional Statements ("If/Then" steps).

1. What is a Loop?

  • A loop is used to repeat an action again and again.
  • In algorithms, we use loops to make a task run multiple times without writing it again and again.

2. Repeat Loop

  • A repeat loop runs the set of steps at least once.
  • It is easy to use a repeat loop if you have already written some steps in pseudocode.
  • How it works: Write Repeat at the start of the steps and Until <condition> at the end. The loop keeps running until the condition becomes true.

3. Forever Loop

  • If you want a set of steps to run continuously or forever, use a forever loop.
  • This loop keeps repeating without stopping unless the program is stopped manually.
  • Example: A clock ticking or a security camera recording.

Nested Loops: Sometimes, one loop is not enough. We can put a loop inside another loop. This is called a Nested Loop.

Nested Loops in Clock: Think of it like a clock:

  • The Outer Loop is like the "Hour" hand (it moves slowly).
  • The Inner Loop is like the "Minute" hand (it must go all the way around before the hour hand moves once).

Nested Loops in a Calendar: (SRQ 3)

It is perfect for a calendar because a calendar has two repeating parts:

  • The Outer Loop (Months): This loop goes from January to December.
  • The Inner Loop (Days): For each month, this loop counts the days (1 to 30 or 31).

When a computer program runs, it needs to remember information. We use two ways to store this information:

  • Constant: A Constant is a piece of data that stays static. This means it never changes from the beginning of the program to the end.
  • Variable: A Variable is an identifier for a memory location where data can change. It can be updated or "overwritten" with a new value while the program is running.

Conditional Statements are like checkpoints in a program. They help the computer decide which path to take. This choice is usually based on a variable value or an event.

Types of Conditional Statements

  • If Statement: Checks a condition and runs a set of steps only if the condition is true. Example: If it is raining, take an umbrella.
  • If-Else Statement: Checks a condition and runs one set of steps if it is true, and another set if it is false. Example: If it is raining, take an umbrella; else, wear sunglasses.
  • Nested If Statement: An if statement inside another if statement to check multiple conditions.
