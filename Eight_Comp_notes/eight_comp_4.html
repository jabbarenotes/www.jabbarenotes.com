Programming languages can be textual or visual:

Textual Programming:

  • We type the code using a keyboard.
  • It is best for students who already have some programming skills and know what they want to create.
  • It uses written commands and syntax rules that must be followed correctly.
  • Example: Python.

Visual Programming:

  • We drag and drop blocks to make programs.
  • It is easier for beginners or casual programmers.
  • It uses graphical blocks that fit together like puzzle pieces.
  • Example: Scratch.

Main Features of a Good Programming Language:

  • It should be easy to use.
  • The rules and structure should be simple.
  • Math and other tasks should be quick and easy to write.
  • Short and simple code helps people do more work faster.

Uses of Programming Languages:

  • C# (C-Sharp): Makes websites, games, and mobile apps.
  • Swift: Makes apps for iPhones, iPads, and Mac computers.
  • Java: Makes professional business applications.
  • Python: Used for modern technologies like Artificial Intelligence (AI).

Programming languages help us create apps, games, business tools, and automation programs.

In Scratch, a program has three main parts:

  1. Sequence Statements: The code runs step by step, one after another.
  2. Conditional Statements: These are conditions that control the flow of the program. They decide what happens next depending on a situation.
  3. Loops: Loops are used to repeat tasks. They help keep the code short and simple by not writing the same instructions many times.

In Scratch, we use conditions to make the program flow correctly.

  • Conditions are checks that can be true or false.
  • If the condition is true, the code runs. If it is false, the code is skipped.

Example with Pico sprite:

  • If the left-arrow key is pressed, Pico moves left 10 steps.
  • If the right-arrow key is pressed, Pico moves right 10 steps.
  • If the sprite reaches the edge, we can use the condition “if on edge, bounce” so it bounces back instead of going out of the screen.
  • We can also change the number of steps (like 100 steps) to test how the sprite moves faster.

Example with collision:

Add another sprite, like a Cat, in Pico’s path. Use an If-Then-Else condition:

  • If Pico touches the Cat, it inverts (like bouncing).
  • Else, it stays upright and keeps moving.

This way, conditions help us control movement and handle collisions in Scratch.

In Scratch, a loop is a set of instructions that repeats many times to do a task. Loops help save time because we do not need to write the same code again and again.

Examples of loops in Scratch:

  • A loop can play a sound file or do a task many times.
  • A wait command can be added to pause 1 second so we can see the output clearly.
  • Loops can also change backgrounds one by one automatically.

Types of loops:

a) Repeat Loop: Repeats the code a fixed number of times. Example: Repeat 10 times to move Pico 10 steps and turn 15 degrees.

b) Repeat Until Loop: Repeats the code until a condition becomes true. Example: Use a Counter variable starting at 0. Every time the loop runs, the counter increases by 1. When the counter reaches 10, the loop stops.

c) Forever Loop: Repeats the code without stopping. To stop it, we need to add a condition inside the loop.

2. Nesting Loops:

  • Loops can be put inside another loop if needed.
  • Example: Pico moves 15 degrees, but before each move, another loop changes four backgrounds one by one.
  • This helps organize complex tasks and make programs easier to read.

In Scratch, functions help us do tasks easily, especially for math operations like addition, subtraction, multiplication, and division. Scratch also has built-in functions that help with special tasks.

Examples of functions in Scratch:

  • Generate Random Numbers: We can get a random number in a certain range. Example: A random number between 1 and 10 can be assigned to a variable called counter.
  • Absolute Function abs(): This ignores the negative sign and gives only the positive value. Example: abs(-9) returns 9.
  • Rounding Numbers:
    • round(): Rounds up if the decimal is greater than 0.4, else rounds down.
    • floor(): Always rounds down.
    • ceiling(): Always rounds up.

Other Useful Functions in Scratch:

Function Name What it Does
sqrt Finds the square root of a number
type Tells the type of an object
pow Finds the power of a number (x^y)
max Finds the largest number from a set
divmod Gives both quotient and remainder
bool Tells if a value is true or false
format Formats a number (e.g., adds "%")
help Gives help about keywords and functions

In Scratch, cloning means making a copy of a sprite. You can make many copies, not just one.

  • Example 1: If you have a snowflake, you can clone it many times to make a snowfall effect.
  • Example 2: In a game, you can create a bullet and clone it to be used multiple times.

To clone a sprite, you can use the create clone of [sprite_name] block. Example: If you click the mouse, the Snowflake sprite can be cloned and appear wherever the mouse is clicked.

Python is a textual programming language that has become very popular in recent years.

  • It is fun to learn and easy to write.
  • You can use Python to develop projects for modern technologies.
  • Python is free, and programs written in Python can run on any computer or platform.
  • Compared to other languages, Python code is usually shorter—about half the size of similar programs in other languages.

Uses of Python: Traffic control systems, E-commerce websites, and entertainment apps like YouTube.

A variable is like a box in the computer’s memory where we can store data.

Example of use:

  1. We create a variable called temp and set it to 0.
  2. The program asks the user to enter a temperature in Celsius. This value is stored in the temp variable.
  3. Using a formula, the program converts the temperature to Fahrenheit.
  4. The result is shown on the screen using the print() function.

A loop in Python is a set of instructions that runs many times to get a result.

for Loop Example:

  • A for loop repeats code for a certain number of times.
  • Python starts the variable i at 0 by default. Each time the loop runs, i increases by 1.
  • If the range is 3, the loop will run 3 times (values of i: 0, 1, 2).
  • Syntax: The for loop line ends with a colon (:), and the code inside must be indented. Indentation tells Python which lines are inside the loop.

A function is a block of code that can be used in different parts of a program. Instead of writing the same code many times, we write it once as a function and use it wherever needed.

Built-in Math Functions in Python:

  • Python has many ready-to-use math functions.
  • To use them, we import the math library in the program.
  • These functions help us do tasks like square roots, powers, and rounding without writing the logic ourselves.

We can write a program in Python to print stars in the shape of a right-angled triangle using nested loops.

Steps:

  1. Think of the screen as rows (horizontal) and columns (vertical).
  2. Use an outer loop to control the rows (e.g., range(0, 5)).
  3. Use an inner loop to control the columns. The loop variable (e.g., j) goes from 0 up to the current value of the row variable.

Result: The stars form a right-angled triangle, growing in size with each row. This demonstrates how loops make creating patterns efficient.
