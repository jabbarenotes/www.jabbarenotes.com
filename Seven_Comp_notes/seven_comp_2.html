A Word Processor is an application software used to write, edit, format, and print documents.

It is used in:

  • Homes
  • Offices / Business
  • Schools and Colleges

Examples of Word Processors:

  • Microsoft Word
  • Apple iWork
  • Google Docs

Steps to start Microsoft Word:

  1. Click the Start icon at the bottom left corner of the screen.
  2. Go to Programs and click on Microsoft Office, then select Word.
  3. Choose to open a Blank document, a recent file, or a template.
  4. Usually, we click on Blank document to start a new page.

The Ribbon is a bar at the top of the Word window. It holds all the tools and buttons we use.

The Ribbon has three parts:

  • Tabs
  • Groups
  • Commands/Buttons

The File Menu (also called the File Tab) is used to manage your documents.

Its main functions are:

  • New: Used to create a new document.
  • Open: Used to open a saved document.
  • Save: Used to save your work.
  • Save As: Used to save a file with a new name or in a different format (like PDF).

The Home Tab in MS Word is a place that has tools to write and change text in a document.

Main Parts of Home Tab:

  1. Clipboard Group: This group helps us to move and copy text.
    • Cut: Removes text
    • Copy: Makes a copy of text
    • Paste: Puts copied text in a new place
    • Format Painter: Copies text style and uses it somewhere else
  2. Font Group: This group helps us to change the style of text.
    • Bold, Italic, Underline: Change text appearance
    • Font and Size: Change the type and size of text
    • Highlight: Add color to highlight text
  3. Paragraph Group: This group helps us to arrange text in a document.
    • Align text: Left, center, or right
    • Bullets and Numbering: Add bullets or numbers to a list
    • Line Spacing: Change the space between lines
  4. Styles: Styles are ready-made text formats. Used for headings, titles and to make the document look neat and organized.

The Insert Tab in MS Word is used to add different items to a document like pictures, tables, and symbols.

Main Features of Insert Tab:

  1. Page Break: Used to start a new page and move text to the next page.
  2. Text Box: Used to write text inside a box.
  3. Table: Used to arrange data in rows and columns.
  4. Symbols: Used to insert special signs (like math symbols).
  5. Header and Footer: Header is text at the top, Footer is text at the bottom of the page.
  6. Page Numbers: Used to add numbers to pages.
  7. Pictures: Used to add images to the document.

The Design Tab in MS Word is used to make a document look beautiful and attractive. It helps to change the style, colors, and overall design of the page.

Main Parts of Design Tab:

  1. Page Background:
    • Page Color: Add color to the page
    • Page Borders: Add borders around the page
    • Watermark: Add light text like “Confidential” or “Sample”
  2. Document Formatting:
    • Themes: Apply ready-made colors and styles to change the look of headings and text.

The Format Tab in MS Word is used to change and edit pictures (images) in a document. It appears when we click on an image.

Main Features of Format Tab:

  1. Arrange Group: Used to set the position of the image (move forward/backward, align, etc.).
  2. Crop Option: Used to cut extra parts of an image.
  3. Adding Text in Image: You can add text inside or on an image using a text box.

The Layout Tab in MS Word is used to change the structure of a document page, such as margins, size, and layout style.

Main Features of Layout Tab:

  1. Page Setup:
    • Margins: Space around the page
    • Size: Choose paper size (A4, Letter, etc.)
    • Orientation: Select portrait or landscape
  2. Columns: Used to divide text into multiple columns like a newspaper.
  3. Breaks: Used to start a new page or section.
  4. Indent: Increase indent moves text to the right, Decrease indent moves text to the left.

1. References Tab:
The References Tab is used for school work, projects, and reports. It helps to add citations, make a table of contents, and organize long documents.

2. Zoom Group:
The Zoom Group is used to change the size of the document on the screen (Zoom in / Zoom out).

3. Quick Access Toolbar:
The Quick Access Toolbar is a small bar at the top left of MS Word. It has important buttons like Save, Undo, and Redo for quick access.

The Review Tab in MS Word is used to check and correct mistakes in a document.

Main Features of Review Tab:

  • Spelling Check: Finds and corrects spelling mistakes
  • Grammar Check: Helps fix grammar errors
  • Thesaurus: Suggests similar words (synonyms)
  • Word Count: Shows the total number of words in the document

The View Tab in MS Word is used to change how a document looks on the screen.

Main Views:

  1. Read Mode: Shows the document like a book. Helps to read easily. Page is split for better reading.
  2. Print Layout: This is the normal view. Shows how the document will look when printed.
  3. Web Layout: Shows how the document will look like a web page. Text appears like a website page.

Scroll Bars:
Scroll bars are bars on the right side and bottom of the screen. They help us move up, down, left, and right in a document to view different parts of the page.

Status Bar:
The Status Bar is a bar at the bottom of MS Word. It shows important information about the document such as page number, word count, and total pages.

Email: Email is a way to send and receive messages using the internet. It is fast, cheap, and easy.

Uses of Email Address:

  • It is used to send emails to other people.
  • It is used to receive emails from others.
  • It is used to create and open an email account.
  • It is used for online registration on websites and apps.

Email Address: It is the address of an email account. It has two parts: username and domain name (Example: pakistan@gmail.com). It is joined by @ symbol.

Username and Password: Username identifies the user. Password is a secret word used to log in to the account.

Email Service Provider: It is a company that gives email service. Examples: gmail.com, yahoo.com, outlook.com.

  1. Open gmail.com in a browser.
  2. Click Create an account.
  3. Fill the form and click Next.
  4. Add a picture or skip it and click Next.
  5. Your Gmail account will be created.

Email Message Parts:

  • From: Shows who sent the email.
  • To: Shows who will receive the email.
  • Subject: Tells the main topic of the email.

Composing and Sending: Fill To, Cc, Bcc, Subject, message box, attach files if needed, then click Send.

Replying: Click Reply.

Forwarding: Click Forward.

Deleting: Click Delete (goes to Trash).

  • Inbox: Folder where received emails are stored.
  • Sent: Folder where all sent emails are saved.
  • Trash: Folder where deleted emails are stored.
  • Spam: Folder where unwanted or junk emails are kept.
  • To: Used to write the main email address of the person who will receive the email.
  • CC (Carbon Copy): Used to send a copy of the email to other people so they can also see it.
  • BCC (Blind Carbon Copy): Used to send a copy of the email to others without showing their email addresses to other receivers.
  • Signature: A short message or name added at the end of an email.

SMTP (Simple Mail Transfer Protocol): Used to send emails from sender’s computer to receiver’s email server.

POP3 (Post Office Protocol 3): Used to receive emails. It takes email from the email server and shows it in the inbox.

Authentication is the process of checking who a user is before giving access to a system or device.

It can be done by:

  • Username and password or PIN
  • Using a card with PIN
  • Using biometrics (fingerprint, face, or voice recognition)
