Problem: A problem is a situation where we need to find a solution.

Problem Solving: Problem solving is a process where we need to find a solution to a problem.

Nowadays, computers help us solve problems quickly and correctly.

Computers use a simple method called Input → Process → Output (IPO):

  • Input: Give data to the computer
  • Process: The computer works on it
  • Output: The computer gives the result

We need to understand the problem area to know the exact problem and find the correct solution. It also helps us use the right information and avoid solving the wrong problem.

The steps of problem solving are:

  1. Identify the problem
  2. Break the problem into small parts (Decompose)
  3. Think of possible solutions
  4. Choose the best solution (Ideal solution)
  5. Apply the solution (Implement)
  6. Check the result (Evaluate)

Followings are the steps:

1. Identify the Problem

Identify problem means finding out exactly what is wrong. You look for the root cause instead of just the symptom. Then we write the problem in simple and clear words.

2. Decompose the Problem

Decompose problem means breaking a big problem into small parts. A large and difficult task is turned into small pieces. This makes the whole process easier to manage.

3. Potential Solutions

Potential Solutions means listing every possible solution to solve the problem. You write down every idea to find the most creative solution.

4. Choose the Best Solution

Choose the Best Solution means picking the ideal plan from all ideas. You check all ideas and select the most effective and efficient one.

5. Implement the Solution

Implement Solution means to implement the chosen plan to solve the problem. You follow the steps carefully and use your tools to solve the problem.

6. Evaluate Solution

Evaluate Solution means checking if the problem is truly solved or not. You compare the result with your goal. If it does not work, you go back and try another idea.

Computational Thinking: Computational thinking is a problem-solving method that breaks a problem into small parts, finds important ideas, and recognizes patterns to plan a solution. It avoids repeated and unnecessary work and improves the effectiveness of problem solving.

Computational Thinking Properties:

  1. Decomposition: Decomposition means breaking a big problem into small and manageable parts so it becomes easier to solve.
  2. Abstraction: Abstraction means removing extra and unimportant details and focusing only on the important information.
  3. Pattern Recognition: Pattern recognition means finding similarities or patterns in problems that have been solved before.
  4. Algorithm Design: Algorithm design means making a step-by-step plan to solve the problem.

We can use decomposition. It means breaking a big problem into small and simple parts so it becomes easier to solve.

Example: A kid getting ready for school

1. Decomposition:

Breaking “getting ready for school” into small parts.

  • Getting the dress ready
  • Taking shower
  • Getting dressed
  • Gathering school books

2. Abstraction:

Abstraction means removing extra details and focusing only on important things. The child ignores clothes choices and only focuses on wearing the school uniform.

3. Pattern Recognition:

Pattern recognition means using past knowledge to understand things. The child knows that before going outside, he combs his hair. So he uses a hair brush even if it is a new one.

4. Algorithm Design:

Algorithm design means writing step-by-step instructions.

Example: Getting dressed

  • Wear the uniform
  • Button the uniform
  • Put on shoes
  • Comb hair

Solution elements are basic tools used to design a solution. There are three elements: Sequence, Repetition, and Conditional Statement.

a. Sequence:

Sequence means doing steps in a fixed order. Steps are followed one by one in order.

b. Repetition:

Repetition means doing a task again and again using loops.

Types of loops:

  • Finite Loop: A loop that runs for a fixed number of times or until a condition becomes false.
  • Infinite Loop: A loop that runs again and again and never stops.

Finite loops types:

  • Counting Loop: A loop that repeats a task a fixed number of times.
  • Event-Controlled Loop: A loop that repeats until a condition becomes false.

c. Conditional Statement:

Conditional statement means making a decision based on a condition. A condition is checked first, then a decision is made.

Example: Write the IF-THEN-ELSE condition for the given statements.

If today is Monday, then yesterday was Sunday.
If today is not Monday, then yesterday was not Sunday.

IF-THEN-ELSE form:

IF today is Monday
THEN yesterday is Sunday
ELSE yesterday is not Sunday

A flowchart is a diagram that shows the steps of a solution using symbols and arrows.

There are five basic flowchart symbols:

  1. Start/End (Oval) 🟢
    It shows the starting or ending point of a flowchart.
  2. Arrow (→)
    It shows the direction or flow between steps.
  3. Input/Output (Parallelogram) ▱
    It shows input or output data.
  4. Process (Rectangle) ▭
    It shows an action or process step.
  5. Decision (Diamond) ◇
    It shows a condition or decision point (Yes/No).
