System Software: The software that are used to solve the problems of the System (Computer) are called System Software e.g Windows, Antivirus etc.

There are four main types of system software:

1. Operating System (OS)

An Operating System is the main software of a computer. It works as a bridge between the user and the computer. It performs these tasks:

  • Controls hardware and software
  • Keeps the computer safe from unauthorized users
  • Loads programs like games and browsers
  • Manages how data is stored and used

Examples: Windows, macOS, Linux, Android

2. Device Driver

Device Drivers help the computer to communicate with hardware devices.

Examples:

  • Printer driver
  • Sound driver

👉 Without drivers, devices like printers or speakers will not work properly.

3. Utility Program: What is a utility program? Give two examples. (SRQ 2)

Utility Programs help to maintain and manage the computer system. They do tasks like:

  • Cleaning the computer
  • Protecting from viruses
  • Managing files
  • Taking backup

Examples: Antivirus, disk cleaner

4. Language Translator

Language Translators convert programming language into machine language (which computer understands).

Examples:

  • Compiler
  • Interpreter
  • Assembler

After you log in to your computer, the first screen you see is called the Desktop. It has different parts. Here are the main parts of the Desktop:

  1. Desktop Icons — Small pictures that represent files, folders, or programs. Examples: This PC, shortcuts
  2. File Explorer — Used to open and manage files and folders in your computer.
  3. Windows Search — Used to search for programs, files, and folders quickly.
  4. Start Button — Located at the bottom-left corner. Used to open programs and settings.
  5. Taskbar Programs — Shows opened or pinned programs for quick access.
  6. Taskbar — A bar at the bottom of the screen that contains: Start Menu, Open programs, Volume, Date & Time
  7. Volume Adjustment — Used to increase or decrease sound.
  8. Date/Time — Shows current date and time and allows you to change it.
  9. Snipping Tool — Snipping Tool is a program used to take a screenshot of a specific part of the screen. You can select any area and capture it as an image.
  10. Microsoft Windows Store — Microsoft Windows Store is an online shop for apps. You can download different applications from here. Some apps are free. Some apps are paid.

An Active Window is the window that you are currently using. It appears in front of all other open windows on the screen.

Window Control Buttons:

  • Minimize — It hides the active window but keeps it running in the background.
  • Restore / Maximize — Maximize: Makes the window fill the whole screen. Restore: Brings the window back to its normal size.
  • Close — It closes the active window completely.

Searching for Programs and Files

Follow these simple steps:

  1. Click on the Windows Search option
  2. Type the name of the program, file, or folder
  3. A list of results will appear
  4. Click on the item you want to open

File
A file is the stored data or information in a computer. It can be different types like: Text, Photo, Music, Video. Each file has a special icon (sign) to show its type.

Folder
A folder is used to organize files. It works like a container where you can keep many files together. A folder can also have other folders inside it, called sub-folders.

Shortcut
A shortcut is an icon that gives quick access to a file or program. It does not contain the actual file, but points to it. Double-clicking a shortcut opens the original file.

Step 1: Go to the place where you want to create the file (like Desktop or a folder).
Step 2: Right-click on any empty area.
Step 3: Click on "New" from the menu.
Step 4: Choose the type of file you want to create (like text file, document, etc.).
Step 5: Type a name for your new file.
Step 6: Double-click the file icon to open and start working.

Step 2: Right-click on an empty area and click on "New".
Step 3: Click on "Folder".
Step 4: Type a name for the new folder.

Step 2: A pop-up menu will appear.
Step 3: Click on "Send to" (this will open another menu).
Step 4: Select "Desktop (create shortcut)".
Step 5: A shortcut icon will appear on your Desktop.

Step 2: Right-click on it and choose:

Step 3: Go to the place where you want the file/folder/shortcut. Right-click and select Paste.

Keyboard Shortcuts:
• Ctrl + X = Cut
• Ctrl + C = Copy
• Ctrl + V = Paste

Deleting a File/Folder/Shortcut:
Step 1: Select the item you want to delete and right-click on it.
Step 2: From the menu, click Delete.
Step 3: A confirmation window will appear. Click Yes to delete or No to cancel.

Restoring a Deleted File/Folder/Shortcut:
Step 1: Double-click the Recycle Bin icon on the Desktop.
Step 2: Find the file/folder you want to restore. Right-click it and select Restore. The item will go back to its original location.

Application Software: The software that are used to solve the problems of the user are called Application Software e.g MS Word, Paint etc

There are different types of Application Software:

i. Entertainment Software — Software used for fun and entertainment. Examples: Windows Media Player, Movies, TV Shows, Music apps

ii. Productivity Software — Used for creating information and doing work. Examples: MS Word, MS PowerPoint, MS Excel

iii. Education and Reference Software — Used to learn and get information. Examples: Online Encyclopedia, Dictionary, Educational Games, Google Maps, Tutorials

Paint 3D is a fun and creative program in Windows 10 that lets you draw and create projects using 2D and 3D tools. It is an updated version of the simple Paint program.

Getting Started:

  1. Open Paint 3D.
  2. Click New to start a new project.
  3. Or go to File → Open to open an existing project.
  4. Click Brushes to start drawing.

Using Brushes:

  1. Move the mouse over a brush to see its name.
  2. Select a brush and draw lines by dragging the mouse.
  3. Try different brush types, colors, thickness, and opacity.
  4. Save your work: Menu → Save, type a name, and click Save.

Creating 2D Shapes:

  1. Click 2D Shapes.
  2. Choose a shape and drag it onto the drawing area.
  3. Change its size, color, or line style using options on the right panel.

Making 3D from Image:

  1. Draw a 2D image first.
  2. Click Make 3D.
  3. Rotate and resize the object.

Tip: Press Ctrl + Z to undo a mistake.

3D Models are objects that you can create in Paint 3D that look like real-world things. They have height, width, and depth (X, Y, Z axes). You can move, rotate, and change them on the Canvas.

Types of 3D Shapes in Paint 3D:

  1. 3D Objects: Cube, Cylinder, Sphere, Hemisphere, Cone, Pyramid
  2. 3D Doodle: Tube Brush, Soft Edge, Sharp Edge
  3. 3D Models: Man, Woman, Dog, Cat, Fish (more models can be downloaded)

Creating 3D Objects:

  1. Click 3D Shapes tool.
  2. Select a Cube.
  3. Choose the material (how it looks).
  4. Drag to create the Cube.
  5. Rotate it around the 3 axes.
  6. Skew or stretch it.
  7. Change the color.
  8. Flip the Cube horizontally or vertically.

Tip: Use Page Up / Page Down to zoom in or out.

Creating 3D Doodles:

  1. Select 3D Shapes → 3D Doodle (Tube Brush, Soft Edge, Sharp Edge).
  2. Choose material.
  3. Draw a closed shape to make it 3D.
  4. Rotate, stretch, and modify like a 3D object.

Canvas: The Canvas is like a 2D sheet of paper where you place your 3D objects. You can move objects in front of or behind the Canvas.

Steps to use Canvas:

  1. Select the Canvas tool.
  2. Explore the different options for size and background.

Crop Tool: The Crop Tool is used to change the Canvas size or remove unwanted parts of your drawing. (SRQ 9)

Adjusting Effects:

  1. Click Effects tool.
  2. Choose a Filter.
  3. Use the Light wheel to change lighting.
  4. See how your 3D objects look.

Here are 5 brush tools in Paint 3D:

  1. Marker – for drawing thin, smooth lines.
  2. Calligraphy Pen – for decorative, artistic writing.
  3. Oil Brush – for painting with oil-like texture.
  4. Watercolor – for soft, blended coloring.
  5. Pixel Pen – for creating pixel-style drawings.

Rapid Typing Tutor is a program that helps you learn to type faster and correctly. It teaches which finger should press which key.

Sitting Posture:

  • Sit straight with back upright.
  • Keep elbows bent at 90°.
  • Face the screen, head slightly forward.
  • Keep 45–70 cm distance from screen.
  • Wrists touch table lightly, don't rest your weight on them.

Home Row:

  • Place fingers on ASDF (left) and JKL; (right) keys.
  • Always start and return to these keys.
  • F and J keys have bumps to find them without looking.

Typing Rules:

  • Press keys with the correct finger.
  • Use Shift with little finger, Space with thumb.
  • Keep even rhythm, imagine key positions.
  • Don't look at keys while typing.

Tips for Speed:

  • Don't rush, go fast only when correct.
  • Practice regularly to avoid mistakes.
  • Read ahead a word or two while typing.
