A computer program is a list of steps (instructions) that a computer follows. It works in three simple parts:

  • Input: The computer gets information from you.
  • Process: It follows instructions to handle that information.
  • Result: The computer shows you the answer.

Small programs may use one algorithm, but big programs can have many algorithms to do different tasks.

Just like humans use languages (like English or Urdu) to talk to each other, we use Programming Languages to talk to computers.

It has its own special words (keywords) and rules (grammar). We use these languages to tell the computer how to solve our problems.

Computer Code: A complete set of instructions written by a programmer to tell the computer what to do. It can be many lines and forms a full program.

Keyword: A special reserved word in a programming language that has a fixed meaning and cannot be changed. It is used to write computer code.

To convert an algorithm into a program, we write each step of the algorithm using Scratch blocks.

Example: Subtraction of Two Numbers

Algorithm Steps (The Plan) Scratch Program (The Action)
1. Input x and y The program asks for two numbers.
2. x = 8 We set the first number to 8.
3. y = 5 We set the second number to 5.
4. Subtract y from x The computer calculates 8 - 5.
5. Result is 3 The character (Sprite) says "3" on the screen.

Scratch: Scratch is a fun way to talk to a computer. Instead of typing hard words, you use colorful blocks that snap together like puzzle pieces. It helps you create your own games and stories!

Components of Scratch interface:

  • Block Palette: Toolbox with all the blocks.
  • Block Category: Groups of blocks sorted by color.
  • Script Area: Work desk where you build your code.
  • Sprites: The characters in your project.
  • Sprite Properties: Size and position of character.
  • Stage: The screen where everything happens.
  • Background: Picture behind the characters.
  • Paint Tool: Draw your own characters or backgrounds.
  • Tutorials: Easy step-by-step lessons.
Category Block Name Action / Result
Motion Move, Turn, etc. Moves and rotates the sprite
Condition If-Then, If-Then-Else Runs code based on conditions
Loop Repeat, Repeat Until, Forever Repeats actions

1. Events: Something that happens and the sprite reacts to it.
Example: When space key pressed → rocket changes direction.

2. Loop: Repeats an action many times.
Example: Move 10 steps, 10 times using Repeat block.

3. Variable: A box that stores a number or value.
Example: count_steps variable that increases every time the sprite moves.
